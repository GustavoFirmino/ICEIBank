# Código por sprint

Cópias de **consulta** dos trechos principais de cada entrega, agrupadas por tema. O projeto que compila e roda está em [`agencia/`](../agencia), [`frontend/`](../frontend) e [`app_mobile/`](../app_mobile); estas pastas não fazem parte do build.

Cada sprint mostra o código **como estava na entrega** (tags `v1.0-sprint1`, `v2.0-sprint2`, `v3.0-sprint3`):

- [`sprint-1/`](sprint-1) — autenticação JWT, contas e partição, relógio de Lamport, transferência e idempotência, logs, frontend
- [`sprint-2/`](sprint-2) — RabbitMQ (pub/sub, dead-letter), relógio vetorial, transferência assíncrona
- [`sprint-3/`](sprint-3) — Bully (eleição, heartbeat, failover), histórico de lideranças, offline-first (backend e app Flutter)
